# WarmestDataStructure
This is a Java project implementing a `WarmestDataStructure` class that meets the following requirements:

- `put(key, value)` – add or update a key-value pair in O(1)
- `get(key)` – retrieve the value for a key in O(1)
- `remove(key)` – remove a key from the structure in O(1)
- `getWarmest()` – retrieve the most recently accessed or added key (not removed) in O(1)
